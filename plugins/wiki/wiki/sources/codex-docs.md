# Codex Documentation Index

## Summary
The Codex documentation index catalogs all official documentation for OpenAI's Codex, an AI coding agent available across multiple interfaces (App, IDE Extension, CLI, and Cloud). The index is notably the largest among the AI coding tools, covering concepts, configuration, security, integrations, automation, administration, and learning resources. The documentation is hosted at `developers.openai.com/codex` and includes detailed coverage of sandboxing, subagents, memories (including a Chronicle feature), and an enterprise administration tier.

## Key Points
- Codex supports four distinct interfaces: App (desktop/web), IDE Extension, CLI, and Cloud -- each with its own documentation section covering features, settings, and commands.
- Core concepts include Prompting, Customization, Memories, Chronicle (memory subsystem), Sandboxing, Auto-review, Subagents, Workflows, Models, and Cyber Safety.
- The Codex App interface includes browser support, a Chrome extension, computer use capabilities, worktrees, local environments, and automations.
- Configuration is tiered: Basic config, Advanced config, Config reference, Config samples, and Speed settings, plus dedicated docs for Rules, Hooks, AGENTS.md, MCP, Plugins, Skills, and Subagents.
- Security documentation includes a dedicated section with overview, setup, threat model, and FAQ -- reflecting Codex's emphasis on safe agent execution.
- Enterprise administration covers authentication, agent approvals and security, remote connections, enterprise admin setup, governance, and managed configuration.
- Automation capabilities include non-interactive mode, a Codex SDK, an App Server, an Agents SDK guide, and a GitHub Action for CI/CD integration.
- Integrations support GitHub, Slack, and Linear for workflow connectivity.
- Learning resources include best practices, videos, and a guide for building AI-native engineering teams.
- Release documentation includes a changelog, feature maturity levels, and open source information.

## Notable Details
- Source URL: `https://developers.openai.com/codex`
- All doc pages follow the pattern `https://developers.openai.com/codex/<section>` or `https://developers.openai.com/codex/<section>/<topic>`
- Enterprise docs use a nested path: `https://developers.openai.com/codex/enterprise/<topic>`
- Concepts docs use a nested path: `https://developers.openai.com/codex/concepts/<topic>`
- Chronicle is a memory subsystem documented at `https://developers.openai.com/codex/concepts/memories/chronicle`
- Auto-review is documented as a sub-feature of sandboxing at `https://developers.openai.com/codex/concepts/sandboxing/auto-review`
- Pricing is documented at `https://developers.openai.com/codex/pricing`
- Migration guide available at `https://developers.openai.com/codex/migrate`
