# API 接口文档模板

每份 API 接口文档必须包含以下章节：

## 必含章节

### 1. 接口概述
- 服务/模块的 API 定位（给谁用、解决什么问题）
- 协议类型（REST/GraphQL/gRPC/CLI/事件）
- 认证方式

### 2. 接口清单
- 表格形式：方法 | 路径/名称 | 用途 | 认证要求
- 按资源/功能分组

### 3. 接口详情
每个接口：
- 请求参数（表格：参数名 | 类型 | 必填 | 说明）
- 响应格式（表格：字段 | 类型 | 说明）
- 错误码（表格：错误码 | 含义 | 触发条件）
- 示例请求/响应

### 4. 数据模型
- 接口涉及的核心数据结构
- 枚举值定义
- 数据校验规则

### 5. 调用模式
- 常见调用序列（Mermaid 序列图）
- 分页/游标模式
- 幂等性保证

### 6. 变更记录
- 版本 | 日期 | 变更内容 | 破坏性

## 质量要求
- 每个接口至少 1 个示例
- 错误码必须包含触发条件
- 序列图展示至少一个典型调用流程
