# 实体文档模板

每份实体 wiki 页面必须包含以下章节：

## 必含章节

### 1. 概述
- 实体名称和一句话定义
- 在系统中的角色
- 重要性评级（核心/重要/辅助）

### 2. 结构
- 字段定义表格（字段名 | 类型 | 说明）
- Mermaid 结构图

### 3. 关系
- 上游关系（被哪些实体引用）
- 下游关系（引用了哪些实体）
- Mermaid 关系图

### 4. 行为
- 核心操作和方法
- 状态转换
- 生命周期

### 5. 约束
- 业务规则
- 数据校验规则
- 不变量

### 6. 代码映射
- 定义文件路径
- 使用位置列表
- 测试文件路径

## 质量要求
- 结构必须包含字段定义表格
- 关系必须区分上游/下游
- 代码映射必须包含实际路径
